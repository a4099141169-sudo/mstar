# Mstar 糖果商城 - 購物車頁面 (1:1 復刻版)

依據 `https://mstar-market.voidandspark.com/mstar-home/cart` 進行 1:1 外觀與功能完整複製。

---

## 🌟 實作功能清單

1. **外觀與佈局 (1:1 原版還原)**：
   - 採用原站 Tailwind v4 樣式（`style.css`），包含全域發光背景色系、字體排版（`shell`、`panel`、`btn-*`、`badge-*`、`input` 等）。
   - 頂部導覽列：糖果漸層 Logo、品牌名稱（糖果商城）、導航連結（逛商品、查訂單）、購物車即時數量徽章。
   - 麵包屑導航：`商城首頁 / 購物車`。
   - 手機版響應式選單折疊與展開。

2. **購物車分組與品項操作**：
   - **依賣家自動拆分分組**：同一位賣家的商品歸為一組，並標明「送出後這一組會是獨立的一張訂單」。
   - **品項明細**：商品縮圖、標題、款式名稱、糖果單價 × 數量 = 小計。
   - **數量增減（Stepper）**：支援 `−` 與 `＋`，受庫存上限（`stockSnapshot`）嚴格約束。
   - **單項商品移除**：移除商品時跳出 Toast 提醒。
   - **整組賣家移除**：「移除這組」按鈕，快速移除該賣家所有商品。
   - **賣家小計與聯絡方式卡片**：
     - 自動解析賣家遊戲 ID 與 DC ID。
     - 點擊「複製遊戲 ID」或「複製 DC ID」一鍵複製，具備複製成功打勾動畫與頂部 Toast 提示。

3. **送出訂單面板（側邊欄 / 黏性定位）**：
   - **摘要統計**：品項數、總件數、產生的訂單張數、合計糖果顆數。
   - **買家資料填寫**：
     - 你的稱呼（選填）
     - 賣家怎麼找到你？（遊戲 ID 與 DC ID 二選一必填，未填時顯示警示）
     - 你的遊戲角色性別（♂ 男角 / ♀ 女角 單選按鈕，必填，附帶提示說明）
     - 備註（選填，附 300 字即時字數計數）
   - **防呆校驗**：若購物車為空、未填聯絡方式或未選性別，按鈕自動鎖定禁用。
   - **免責與交易聲明**：站內不經手金流與糖果，遊戲內交易說明。

4. **訂單建立與結果畫面 (Order Result)**：
   - 送出時具備「送出中…」載入狀態。
   - 自動依各賣家拆分為獨立訂單編號（`OR-xxxxxx`）。
   - 送出完成後展示訂單結果彈窗，清楚列出各訂單明細與狀態（等賣家處理）。
   - 提供「📋 複製全部訂單文字」與個別「複製此訂單」按鈕，自動格式化成可在遊戲內或 Discord 直接發送給賣家的文字格式。

5. **狀態同步與持久化 (LocalStorage)**：
   - `mstar.cart`：購物車品項儲存。
   - `mstar.buyer`：買家姓名、遊戲 ID、DC ID、性別記憶。
   - `mstar.myOrders`：歷史訂單編號儲存。
   - `mstar.lastOrders`：最近一次送出的訂單明細。

6. **測試與體驗工具**：
   - 頂部工具列提供「🔄 載入示範商品」及「⚠️ 測試庫存衝突」，方便即時體驗各狀態（含購物車清空、空狀態畫面、庫存衝突紅框警示等）。

## 🚀 啟動方式

### 方法一：使用 Node.js 本地伺服器（推薦）

專案根目錄已內建本地伺服器：

```bash
npm start
# 或
node server.js
```

瀏覽器開啟：`http://localhost:3000/`

---

## 📁 檔案結構

- `index.html`：購物車核心 HTML 結構與 Vue 3 掛載點
- `app.js`：Vue 3 響應式邏輯、分組計算、儲存管理、訂單處理
- `style.css`：原站 Tailwind v4 完整編譯樣式表
- `favicon.svg`：原站 SVG 圖示
- `assets/vue.global.js`：Vue 3 獨立運行環境（離線可用）
- `media/`：示範商品本地圖片快取
- `server.js`：零依賴靜態伺服器
