                    Mstar 糖果商城與商品上架系統 - 最直白操作手冊
================================================================================

您好！本手冊針對本次調整（前台純瀏覽、登入權限系統、防暴力密碼鎖定、後台帳號增刪與密碼管理、
Discord 新訂單即時推播、舊玩家資訊清除）提供最簡單直白的操作教學。

所有資料皆保存在本機真實資料庫（data.db），舊的抓取玩家資料已完全移除！

--------------------------------------------------------------------------------
【一、如何啟動與打開網站】
--------------------------------------------------------------------------------
1. 在資料夾開啟終端機（PowerShell 或 CMD）
2. 輸入指令啟動伺服器：
   npm start
   （或輸入：node server.js）

3. 在瀏覽器打開網址：
   http://localhost:3000/

※ 停止伺服器：在終端機視窗按下 Ctrl + C 即可。


--------------------------------------------------------------------------------

--------------------------------------------------------------------------------
【三、前台怎麼逛？買家如何使用？】
--------------------------------------------------------------------------------
1. 前台已移除上架按鈕，畫面乾淨清爽，專門給買家瀏覽選購。
2. 買家可以透過上方「分類標籤」或「搜尋欄位」挑選商品。
3. 點擊【＋ 加入購物車】後，進入【🛒 購物車】。
4. 購物車會自動將同一個賣家的商品分成同一張訂單，買家填寫遊戲角色 ID 與性別後，
   點擊【送出訂單】，訂單就會即時寫入資料庫！
   ※ 若後台有設定 Discord Webhook，送出訂單的瞬間您的 Discord 就會即時收到通知！


--------------------------------------------------------------------------------
【四、如何登入後台？】
--------------------------------------------------------------------------------
1. 在網站右上角點擊【👤 賣家登入】按鈕。
2. 輸入帳號（例：aya）與密碼（例：aya123）。
3. 登入成功後，右上角會顯示「aya (管理員)」，並且出現【⚙️ 上架與管理】按鈕！
4. 點擊【⚙️ 上架與管理】即可進入後台系統。
5. 想要切換身分或離開時，隨時點擊【登出】即可。


--------------------------------------------------------------------------------
【五、後台如何編輯、新增與刪除帳號？】
--------------------------------------------------------------------------------
進入後台後，點擊次選單的【👥 帳號密碼管理】：

1. 【修改帳號的密碼】：
   - 找到要修改的帳號，點擊旁邊的【✏️ 編輯 / 修改密碼】。
   - 在跳出的視窗中直接輸入新密碼，也可以順便修改顯示名稱、遊戲 ID、Discord ID。
   - 點擊【儲存更新】，密碼立即生效！下次登入就要用新密碼囉！

2. 【建立新賣家帳號（讓其他朋友也能登入上架）】：
   - 點擊右上角【＋ 建立新賣家帳號】。
   - 填寫：登入帳號 (Username)、登入密碼 (Password)、顯示名稱 (上架看到的名字)、
     遊戲角色 ID、Discord 帳號。
   - 點擊確認建立後，您的朋友就可以直接在前台用這組帳號密碼登入了！

3. 【刪除帳號】：
   - 每個帳號旁皆有【🗑️ 刪除帳號】按鈕（系統預設防呆保護：自己不能刪除目前正在登入的帳號）。
   - 點擊刪除並確認後，該帳號將從資料庫中永久移除。


--------------------------------------------------------------------------------
【六、如何設定 Discord 訂單推播通知？】
--------------------------------------------------------------------------------
當買家在購物車點擊「送出訂單」時，您可以直接在 Discord 伺服器收到即時通知：

1. 在您的 Discord 伺服器中，任選一個頻道 -> 點擊頻道設定（齒輪圖示）->「整合」->「Webhooks」->「新增 Webhook」-> 點擊「複製 Webhook 網址」。
2. 進入商城後台，點擊次選單的【🔔 通知設定】。
3. 把剛才複製的 Discord Webhook 網址貼入輸入框中，點擊【儲存 Webhook 設定】。
4. 點擊【發送測試訊息】按鈕，立刻檢查 Discord 是否跳出綠色機器人測試訊息！
5. 設定完成後，以後只要有任何買家送出訂單，Discord 就會立刻發出漂亮的卡片通知，包含買家遊戲 ID、性別、商品清單、總糖果數等完整資訊！


--------------------------------------------------------------------------------
【七、後台如何上架商品？（上誰的名字、傳圖、勾選分類）】
--------------------------------------------------------------------------------
在後台點擊【➕ 商品上架】：

1. 【上誰的名字】：
   - 下拉選單中會列出目前所有已建立的賣家帳號。
   - 選擇要掛在哪位朋友的名字下，前台與購物車就會自動顯示他的名字與聯絡方式。

2. 【商品名稱】：
   - 填寫家具名稱（例如：星空雙人床、夢幻噴泉...）。

3. 【商品圖片】：
   - 點擊方框選取電腦裡的圖片，會自動上傳至專案的 `uploads/` 資料夾並即時預覽。

4. 【勾選分類】：
   - 用滑鼠打勾勾選擇分類（可多選），也可以點【＋ 新增分類標籤】自訂全新分類。

5. 【價格與庫存】：
   - 設定需要多少顆糖果與現貨數量。若有多款顏色或尺寸，可打開「是否有多種款式」開關。

6. 【確認上架】：
   - 點擊【🚀 確認上架至商城資料庫】，商品立刻出現在前台，買家馬上就能買！
